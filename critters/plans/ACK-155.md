# ACK-155: Cache computeMetricsSummary in health server

## Summary

Add a 30-second TTL cache to `computeMetricsSummary()` in `src/health.ts` so that repeated `/healthz` requests don't re-read and re-parse the entire metrics JSONL file each time. Also export a cache-reset helper for test isolation.

## Files to Modify

### 1. `src/health.ts`

**Add module-level cache variables** (after the imports, before `startHealthServer`):

```ts
let cachedSummary: { totalTasks: number; succeeded: number; failed: number } | null = null;
let cachedAt = 0;
const CACHE_TTL_MS = 30_000;
```

**Modify `computeMetricsSummary()`** to return cached value when fresh:

```ts
function computeMetricsSummary(): { totalTasks: number; succeeded: number; failed: number } {
  const now = Date.now();
  if (cachedSummary && now - cachedAt < CACHE_TTL_MS) {
    return cachedSummary;
  }

  const all = getRecentMetrics(10000);
  let totalTasks = 0;
  let succeeded = 0;
  let failed = 0;
  for (const m of all) {
    if (m.event === "task_completed") {
      totalTasks++;
      succeeded++;
    } else if (m.event === "task_failed") {
      totalTasks++;
      failed++;
    }
  }

  cachedSummary = { totalTasks, succeeded, failed };
  cachedAt = now;
  return cachedSummary;
}
```

**Add exported cache-reset function** for test isolation:

```ts
export function resetMetricsSummaryCache(): void {
  cachedSummary = null;
  cachedAt = 0;
}
```

### 2. `src/__tests__/health.test.ts`

**Import `resetMetricsSummaryCache`** alongside the existing health imports:

```ts
import { type HealthStatus, startHealthServer, resetMetricsSummaryCache } from "../health.js";
```

**Call `resetMetricsSummaryCache()` in `beforeEach`** to ensure each test starts with a clean cache:

```ts
beforeEach(() => {
  const tmp = createTempDir();
  tempDir = tmp.path;
  cleanup = tmp.cleanup;
  resetMetricsSummaryCache();
});
```

**Add a new test** in the `GET /healthz` describe block to verify caching behavior:

```ts
test("caches metrics summary across rapid requests", async () => {
  const metricsFile = join(tempDir, "metrics.jsonl");
  initMetrics(metricsFile);
  recordMetric({ timestamp: "", event: "task_completed", issueId: "C-1" });

  const port = 10000 + Math.floor(Math.random() * 50000);
  server = startHealthServer(port, defaultStatus);

  // First request computes fresh
  const res1 = await fetch(`http://localhost:${port}/healthz`);
  const body1 = await res1.json();
  expect(body1.metrics.totalTasks).toBe(1);
  expect(body1.metrics.succeeded).toBe(1);

  // Add another metric — but cache should still return old value
  recordMetric({ timestamp: "", event: "task_failed", issueId: "C-2" });

  const res2 = await fetch(`http://localhost:${port}/healthz`);
  const body2 = await res2.json();
  // Should still be cached (1 task, not 2)
  expect(body2.metrics.totalTasks).toBe(1);
  expect(body2.metrics.succeeded).toBe(1);
  expect(body2.metrics.failed).toBe(0);
});
```

## Dependencies / Setup

None. No new packages or config changes required.

2. Run `bun test` to verify all existing tests pass (the cache reset in `beforeEach` ensures test isolation).
3. The new test verifies that within the TTL window, the cached value is returned even after new metrics are recorded.
