# ACK-140: Fix periodic title update overwriting critter pane titles

## Summary

The periodic pane title update in `src/index.ts` uses `select-pane -t config.tmuxSession` to set the title, which targets whatever pane is currently active in the session. This means it overwrites critter pane titles (e.g., "ACK-94: Add playbook selector… / plan") with the daemon status title ("Critters v0.4.3 | up 5m 2s | 1 active"). The fix is to capture the main pane's ID at startup and target it explicitly in all title updates.

## Files to modify

### `src/index.ts`

Three changes are needed, all within the `main()` function:

#### 1. Capture the main pane ID after tmux session setup (line ~199)

After the `if (!noTmux)` block that configures pane border styling, capture the current pane's ID. Since the daemon process is running inside the main pane, `display-message -p` will return the pane ID of the calling pane.

Add after line 198 (inside the existing `if (!noTmux)` block, before the title set):

```ts
// Capture main pane ID so periodic title updates only affect this pane
const mainPaneResult = await runCommand("tmux", ["display-message", "-t", config.tmuxSession, "-p", "#{pane_id}"]);
const mainPaneId = mainPaneResult.stdout.trim();
```

#### 2. Update initial title set to use pane ID (line ~201)

Change:
```ts
await runCommand("tmux", ["select-pane", "-t", config.tmuxSession, "-T", `Critters v${VERSION}`]).catch(() => {});
```

To:
```ts
await runCommand("tmux", ["select-pane", "-t", mainPaneId, "-T", `Critters v${VERSION}`]).catch(() => {});
```

#### 3. Update periodic title interval to use pane ID (line ~263)

Change:
```ts
runCommand("tmux", ["select-pane", "-t", config.tmuxSession, "-T", title]).catch(() => {});
```

To:
```ts
runCommand("tmux", ["select-pane", "-t", mainPaneId, "-T", title]).catch(() => {});
```

Note: `mainPaneId` is declared inside the `if (!noTmux)` block (line 199). The periodic interval (line 258) is also guarded by `if (!noTmux)`, but it's a separate block. We need to declare `mainPaneId` in a scope accessible to both. The cleanest approach: declare `let mainPaneId: string | undefined;` before the first `if (!noTmux)` block (around line 198), assign it inside the block, and reference it in the interval block.

### Detailed code structure

```ts
// Before line 199
let mainPaneId: string | undefined;

if (!noTmux) {
  // Capture main pane ID so periodic title updates only affect this pane
  const mainPaneResult = await runCommand("tmux", ["display-message", "-t", config.tmuxSession, "-p", "#{pane_id}"]);
  mainPaneId = mainPaneResult.stdout.trim();

  // Set main pane title (using captured pane ID)
  await runCommand("tmux", ["select-pane", "-t", mainPaneId, "-T", `Critters v${VERSION}`]).catch(() => {});
  // Configure pane border styling (these target the session, which is correct for session-wide settings)
  await runCommand("tmux", ["set", "-t", config.tmuxSession, "pane-border-status", "top"]).catch(() => {});
  await runCommand("tmux", ["set", "-t", config.tmuxSession, "pane-border-format", " #{pane_title} "]).catch(() => {});
  await runCommand("tmux", ["set", "-t", config.tmuxSession, "pane-border-style", "fg=colour240"]).catch(() => {});
  await runCommand("tmux", ["set", "-t", config.tmuxSession, "pane-active-border-style", "fg=colour39"]).catch(() => {});
}

// ...

// Periodic main pane title update (later in the function, ~line 258)
let titleInterval: ReturnType<typeof setInterval> | null = null;
if (!noTmux) {
  titleInterval = setInterval(() => {
    const uptime = formatDuration(Date.now() - startTime);
    const active = spawner.getActiveCount() + reviewSpawner.getActiveCount();
    const title = `Critters v${VERSION} | up ${uptime} | ${active} active`;
    runCommand("tmux", ["select-pane", "-t", mainPaneId!, "-T", title]).catch(() => {});
  }, 60_000);
  titleInterval.unref();
}
```

## No other files need changes

- `src/claude.ts` already correctly targets critter panes by their specific `paneId` (line 128: `select-pane -t ${paneId}`), so no changes needed there.
- `src/utils.ts`, `src/types.ts`, `src/config.ts` — no changes needed.
- The `tmux set` commands for border styling correctly target the session (they're session-level settings, not pane-level), so they remain unchanged.

## Testing approach

1. **Manual testing**: Start the daemon in a tmux session, trigger a critter task, and verify:
   - The main pane title shows "Critters v{VERSION} | up {duration} | {n} active"
   - Critter panes show their task titles (e.g., "ACK-94: Add playbook… / plan")
   - After 60 seconds (when the periodic update fires), critter pane titles are not overwritten
2. **Edge case**: Start daemon, wait for periodic update, split a pane manually — the manual pane's title should not be affected.

## Dependencies

None — this is a self-contained change to `src/index.ts`.
