## Detailed Changes

### 1. Fix x-axis label cramping

**Current:** Lines 429, 455 use `d.date.slice(5)` (produces "03-05") for bar labels.
**Change:** Replace with `formatShortDate(d.date)` (produces "Mar 5"). The `formatShortDate` function already exists at line 51. The `shortDate` variable is already computed on lines 430/456 but unused for the label.

Specifically:
- Line 436: Change `${escapeHtml(label)}` to `${escapeHtml(shortDate)}` (tasks chart)
- Line 461: Same change (cost chart)
- Apply same pattern to the new duration chart

The mobile CSS at line 293 already handles rotation (-45deg) and hides every-other label (`:nth-child(even) .bar-label { visibility: hidden }`), so mobile is already handled.

### 2. Replace Success vs Failure with SVG donut chart

**Current:** Lines 468-484 render a two-bar chart with "Pass" and "Fail" bars.
**Change:** Replace with an inline SVG donut chart using `<svg viewBox="0 0 36 36">` and two `<circle>` elements.

Implementation:
- Use a `<circle>` with `r="15.9155"` (circumference ~100) centered at `(18,18)` for easy percentage-based `stroke-dasharray`
- Green circle (`var(--success)`) for succeeded percentage: `stroke-dasharray: "<successPct>, 100"`
- Red circle (`var(--failure)`) for failed percentage: `stroke-dasharray: "<failPct>, 100"` with `stroke-dashoffset: -<successPct>` to position after the green segment
- Background circle in `var(--border)` color for the ring outline
- Center text showing `${successRate}%` using `<text>` element centered in the SVG
- Legend below: `<div>` with "X passed · Y failed" text
- Handle edge case: when `totalTasks === 0`, show an empty ring with "N/A" in center

CSS additions:
- `.donut-chart` — flex container, centered, with appropriate sizing
- `.donut-text` — centered text styling for the percentage in the SVG
- `.donut-legend` — small text below the donut

SVG structure:
```html
<svg viewBox="0 0 36 36" class="donut-svg">
  <circle cx="18" cy="18" r="15.9155" fill="none" stroke="var(--border)" stroke-width="2.5"/>
  <circle cx="18" cy="18" r="15.9155" fill="none" stroke="var(--success)" stroke-width="2.5"
    stroke-dasharray="<successPct>, 100" stroke-dashoffset="25" stroke-linecap="round"/>
  <circle cx="18" cy="18" r="15.9155" fill="none" stroke="var(--failure)" stroke-width="2.5"
    stroke-dasharray="<failPct>, 100" stroke-dashoffset="<25 - successPct>" stroke-linecap="round"/>
  <text x="18" y="18" class="donut-text">XX%</text>
</svg>
```

Note: `stroke-dashoffset="25"` rotates the start to the top (12 o'clock position). The failure segment offset is `25 - successPct` so it starts right after the success segment.

### 3. Add "Avg Duration per Day" chart

**Type changes:**
- Update `DayStat` type (line 60) to add `avgDuration: number` field (in milliseconds, 0 if no data)

**Computation changes in `computeDailyStats`:**
- Add tracking fields to the date map entries: accumulate total duration and count
- For each `task_completed` or `review_completed` event with a valid `duration`, add to the day's total and increment count
- Compute `avgDuration = totalDuration / count` (or 0 if count is 0) for each day
- Implementation: use a parallel `Map<string, { totalDur: number; durCount: number }>` or extend the stat object with temporary fields, then clean up

**Chart rendering:**
- Compute `maxDurationPerDay` from the stats using `niceMax` (not isCost)
- Add a new chart card after the cost chart (before the donut chart)
- Same structure as cost chart: `chart-with-axis` wrapper with y-axis and bar-chart
- Bar color: `#8B5CF6` (purple) — add CSS class `.bar.duration { background: #8B5CF6; }`
- Y-axis labels: format as minutes — `formatDurationMinutes(ms)` helper that returns e.g. "0m", "5m", "10m"
  - Simple implementation: `Math.round(ms / 60000) + "m"`
  - For the max label and mid label
- X-axis labels: use `formatShortDate(d.date)` (same as other charts)
- Tooltip: show human-readable duration using `fmtDuration`

**New helper function:**
```typescript
function formatDurationMinutes(ms: number): string {
  if (ms <= 0) return "0m";
  const mins = Math.round(ms / 60000);
  return `${mins}m`;
}
```

**niceMax adjustment:** For the duration chart, call `niceMax(rawMaxDuration / 60000, false) * 60000` — normalize to minutes, get a nice max in minutes, then convert back to ms. This ensures y-axis labels show clean minute values.

## Edge Cases

- **No metrics at all:** All charts show empty bars (height 0%), donut shows "N/A", duration chart shows 0m
- **Days with no completed tasks:** `avgDuration` = 0, bar height = 0%
- **Duration missing on some events:** Only count events that have a valid `duration` field
- **Very large durations (hours):** `formatDurationMinutes` will show e.g. "120m" — acceptable for y-axis labels. The tooltip uses `fmtDuration` which handles hours
- **All tasks succeed (0 failures):** Donut shows full green ring, "100%", legend "X passed · 0 failed"
- **All tasks fail (0 successes):** Donut shows full red ring, "0%", legend "0 passed · Y failed"

2. Cost per Day (Last 14 Days) — bar, gold

This puts the three time-series bar charts together and the summary donut last.
