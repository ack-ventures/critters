#### Setup Pattern

Each test needs a bare repo to clone from and a temp dir to clone into. The bare repo needs at least one commit for `git clone` to work. The setup creates an initial commit by cloning the bare repo to a temp dir, adding a file, committing, and pushing back.

The bare repo is explicitly initialized with `main` as the default branch (using `-b main` flag on `git init --bare`) to avoid environment-dependent flakiness from different `init.defaultBranch` settings.

```typescript
let bareRepo: { path: string; cleanup: () => void };
let tempDirs: string[]; // track all temp dirs for cleanup

beforeEach(() => {
  bareRepo = createTestRepo(); // Note: may need to pass "-b main" — see below
  tempDirs = [];
  // Seed the bare repo with an initial commit on "main" branch
  const seedDir = mkdtempSync(join(tmpdir(), "critters-seed-"));
  tempDirs.push(seedDir);
  execSync(`git clone ${bareRepo.path} ${seedDir}/work`, { stdio: "ignore" });
  execSync("git checkout -b main", { cwd: `${seedDir}/work`, stdio: "ignore" });
  execSync("git config user.email test@test.com", { cwd: `${seedDir}/work`, stdio: "ignore" });
  execSync("git config user.name Test", { cwd: `${seedDir}/work`, stdio: "ignore" });
  writeFileSync(`${seedDir}/work/README.md`, "init");
  execSync("git add -A && git commit -m 'init'", { cwd: `${seedDir}/work`, stdio: "ignore" });
  execSync("git push -u origin main", { cwd: `${seedDir}/work`, stdio: "ignore" });
  // Set origin/HEAD in the bare repo so getDefaultBranch works
  execSync("git symbolic-ref HEAD refs/heads/main", { cwd: bareRepo.path, stdio: "ignore" });
});

afterEach(() => {
  bareRepo.cleanup();
  for (const dir of tempDirs) {
    rmSync(dir, { recursive: true, force: true });
  }
});
```

A helper to clone from the bare repo and configure git user settings in the clone:

```typescript
function cloneDir(): string {
  const { path } = createTempDir();
  tempDirs.push(path);
  return join(path, "repo");
}

async function cloneAndSetup(): Promise<string> {
  const target = cloneDir();
  await shallowClone(bareRepo.path, target, "test");
  execSync("git config user.email test@test.com", { cwd: target, stdio: "ignore" });
  execSync("git config user.name Test", { cwd: target, stdio: "ignore" });
  return target;
}
```

The `cloneDir()` helper returns a path inside the temp dir (not the temp dir itself) because `shallowClone` creates the target directory during clone. The `cloneAndSetup()` helper also configures `user.email` and `user.name` in the clone so that `git commit` works without depending on global git config.

#### Test Cases

**`describe("shallowClone")`**

1. **clones from local bare repo** — Call `shallowClone(bareRepo.path, target, "test")`, verify `existsSync(target)` and `existsSync(join(target, ".git"))` are both true. Also verify `existsSync(join(target, "README.md"))` to confirm content was cloned.

2. **works with cwd parameter** — Create a parent temp dir, call `shallowClone(bareRepo.path, "subdir", "test", parentDir)` with a relative target and explicit `cwd`. Verify the clone exists at `join(parentDir, "subdir", ".git")` and that `README.md` exists inside the clone.

3. **throws on invalid repo URL** — Call `shallowClone("file:///nonexistent/repo", target, "test")` and expect it to throw with a message containing "git clone failed".

**`describe("createBranch")`**

1. **creates a new branch** — Clone first, then `createBranch(clonePath, "test-branch", "test")`. Run `git branch` in the clone dir and verify stdout contains "test-branch" and it's the current branch (marked with `*`).

2. **throws on invalid workDir** — Call `createBranch("/nonexistent", "branch", "test")` and expect it to throw.

**`describe("getDefaultBranch")`**

1. **detects default branch from origin/HEAD** — Clone from bare repo (which has `HEAD` pointing to `main`), call `getDefaultBranch(clonePath, "test")`. Verify it returns `"main"`.

2. **falls back to "main" when origin/HEAD is not set** — Clone from bare repo, then remove `origin/HEAD` ref with `git remote set-head origin -d`. Call `getDefaultBranch(clonePath, "test")`. Verify it returns `"main"`.

**`describe("hasCommitsOnBranch")`**

1. **returns false with no commits on branch** — Clone, create branch "feature", call `hasCommitsOnBranch(clonePath, "feature", "test")`. Should return `false`.

2. **returns true after committing on branch** — Clone, create branch "feature", write a file, commit it (using `execSync` directly for test isolation), call `hasCommitsOnBranch(clonePath, "feature", "test")`. Should return `true`.

**`describe("hasUncommittedChanges")`**

1. **returns false on clean repo** — Clone, call `hasUncommittedChanges`. Should return `false`.

2. **returns true with modified file** — Clone, modify `README.md`, call `hasUncommittedChanges`. Should return `true`.

3. **returns true with new untracked file** — Clone, create a new file, call `hasUncommittedChanges`. Should return `true`.

**`describe("autoCommit")`**

1. **commits all uncommitted changes** — Clone (with git config set via `cloneAndSetup`), modify a file, call `autoCommit(clonePath, "test", "auto commit msg")`. Run `git log --oneline` and verify the output contains "auto commit msg". Also verify `hasUncommittedChanges` returns `false` afterward.

2. **handles nothing to commit** — Clone (with git config set via `cloneAndSetup`), call `autoCommit` on a clean repo. Should not throw (the function logs an error internally but does not propagate it).

**`describe("commitFile")`**

1. **commits a specific file** — Clone (with git config set via `cloneAndSetup`), create a new file `test.txt`, call `commitFile(clonePath, "test.txt", "add test file", "test")`. Run `git log --oneline` and verify "add test file" appears. Also run `git show --name-only HEAD` and verify `test.txt` is listed.

2. **skips when file already committed** — Clone (with git config set via `cloneAndSetup`), create a file, commit it with `commitFile`, then call `commitFile` again with the same file and a different message. Run `git log --oneline` and verify the second message does NOT appear. Also verify `git rev-list --count HEAD` returns 2 (init + first commitFile only).

**`describe("cleanupWorkDir")`**

1. **removes existing directory** — Create a temp dir, call `cleanupWorkDir(path)`, verify `existsSync(path)` returns `false`.

2. **does not throw for non-existent directory** — Call `cleanupWorkDir("/tmp/critters-nonexistent-" + Date.now())` — should not throw.

**`describe("cleanupStaleWorkDirs")`**

1. **removes inactive dirs but keeps active ones** — Create a base temp dir with 3 subdirectories (`a`, `b`, `c`). Create an `activeWorkDirs` Set containing only the full path of `b`. Call `cleanupStaleWorkDirs(basePath, activeSet)`. Verify `a` and `c` are gone, `b` still exists.

2. **handles non-existent base dir** — Call `cleanupStaleWorkDirs("/tmp/critters-nonexistent-" + Date.now())` — should not throw.

3. **cleans all dirs when no active set** — Create a base dir with 2 subdirs. Call `cleanupStaleWorkDirs(basePath)` with no `activeWorkDirs` argument. Verify both subdirs are removed.

**`describe("shallowClone retry logic")`**

Test that `shallowClone` retries on ENOENT errors using `mock.module` to mock `../utils.js`.

1. **retries on ENOENT and succeeds** — Use `mock.module` to replace `runCommand` and `sleep`:

```typescript
describe("shallowClone retry logic", () => {
  test("retries on ENOENT and succeeds", async () => {
    let callCount = 0;
    mock.module("../utils.js", () => ({
      runCommand: async () => {
        callCount++;
        if (callCount === 1) {
          return { code: 1, stdout: "", stderr: "ENOENT" };
        }
        return { code: 0, stdout: "", stderr: "" };
      },
      sleep: async () => {},
    }));
    // Re-import to pick up mocked module
    const { shallowClone: mockedClone } = await import("../git.js");
    const target = cloneDir();
    await mockedClone(bareRepo.path, target, "test");
    expect(callCount).toBe(2);
  });
});
```

If `mock.module` does not work reliably with ESM re-imports in practice, the implementation should fall back to verifying the retry behavior through the error path: call `shallowClone` with an invalid URL and verify that the thrown error message contains "git clone failed" (confirming all retries were exhausted). This is less precise but still validates that the retry loop ran. The implementation phase should try `mock.module` first and only fall back if it doesn't work.
