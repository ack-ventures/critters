# ACK-127: Update README.md and CLAUDE.md with v0.4.0 features

## Summary

Update both documentation files to reflect features added since v0.3.1: new CLI commands (`status`, `retry`, `logs`, `init-repo`), CLI flags (`--dry-run`, `--no-tmux`, `--skip-update`, `--config`), web dashboard/health endpoint, `healthPort` config, shell hooks, `maxPlanningTurns`/`maxExecutionTurns` split, `planningModel`/`executionModel`, `maxLogSizeMb`, and new source files.

## Files to modify

### 1. README.md

#### A. Add new CLI commands to the Commands section (lines 15–21)

Add the following entries after the existing commands, matching the existing `- \`critters ...\` — description` format:

```markdown
- `critters status` — show daemon status (active/queued critters, today's stats)
- `critters retry <ID>` — retry a failed critter (reset to Todo)
- `critters logs <ID>` — show logs for a critter run
- `critters init-repo` — scaffold `.critters.yaml` in the current repo
```

#### B. Add flags section

Add a `### Flags` subsection after the Commands list with all documented flags from `src/index.ts` help text:

```markdown
### Flags

- `--dry-run` — poll once, show what would happen, and exit
- `--no-tmux` — run without tmux (log to file instead)
- `--skip-update` — skip auto-update check on startup
- `--config PATH` — use a custom config file
```

#### C. Add web dashboard and health endpoint section

Add a new `## Web Dashboard` section after the Configuration section (before "Creating tickets"):

```markdown
## Web Dashboard

The daemon runs an HTTP server on port 3847 (configurable via `healthPort`, set to 0 to disable).

| Route | Description |
|---|---|
| `/` or `/dashboard` | Live dashboard with task stats, charts, and recent activity |
| `/healthz` | JSON health check (uptime, version, active/queued counts, metrics summary) |
| `/metrics` | JSON array of recent metric events |

`critters status` queries the health endpoint to display a quick summary in the terminal.
```
