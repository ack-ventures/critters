# ACK-243: Dashboard — link Issue column to tracker ticket, add logs link

## Summary

The recent activity table in the dashboard currently links the Issue column to the internal logs page (`/dashboard/{id}`). This plan changes it to link to the actual tracker ticket (Linear/Jira URL) and adds a separate logs link so users can still access logs.

## Changes

### 1. Add `issueUrl` to `MetricEvent` (`src/metrics.ts`)

Add `issueUrl?: string` to the `MetricEvent` type (after `prUrl` on line 26).

### 2. Pass `issueUrl` in all `recordMetric` calls (`src/unified-spawner.ts`)

There are 6 `recordMetric` calls that include `identifier`. Each needs `issueUrl: task.issueUrl` added:

- **Line 234** — `task_started` / `review_started`
- **Line 581** — `task_completed` (non-PR success path)
- **Line 706** — `task_failed` / `review_failed`
- **Line 831** — `task_completed` (PR success path)
- **Line 891** — `review_completed` (merged)
- **Line 932** — `review_completed` (needs_changes)

For all calls, add: `...(task.issueUrl ? { issueUrl: task.issueUrl } : {})`

This follows the existing pattern used for `prUrl` (e.g., line 240: `...(task.prUrl ? { prUrl: task.prUrl } : {})`).

### 3. Update dashboard Issue column (`src/dashboard.ts`, ~line 811)

**Current code:**
```ts
const idLink = rawId ? `<a href="/dashboard/${encodeURIComponent(rawId)}">${id}</a>` : id;
```

**New code:**
```ts
const issueHref = m.issueUrl
  ? escapeHtml(m.issueUrl)
  : `/dashboard/${encodeURIComponent(rawId)}`;
const issueTarget = m.issueUrl ? ' target="_blank" rel="noopener"' : '';
const idLink = rawId ? `<a href="${issueHref}"${issueTarget}>${id}</a>` : id;
```

This links to the tracker ticket when `issueUrl` is present, and falls back to the logs page for older metrics without `issueUrl`.

### 4. Add a Logs link column

**Table header** (~line 787): Add `<th>Logs</th>` after the PR column header (before "When").

**Table body** (~line 818): Add a logs cell after the PR cell:
```ts
const logsLink = rawId
  ? `<a href="/dashboard/${encodeURIComponent(rawId)}" title="View logs">logs</a>`
  : '\u2014';
```
Then in the row template: `<td>${logsLink}</td>`

**Empty state colspan**: Update from `colspan="7"` to `colspan="8"` on line 792.

## Edge Cases

- **Older metrics without `issueUrl`**: Issue column falls back to linking to logs page (same as current behavior). Logs column always shows a link when `rawId` exists.
- **Missing `identifier`/`issueId`**: Both Issue and Logs columns show em-dash (no link), matching current behavior.
