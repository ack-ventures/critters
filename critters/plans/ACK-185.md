# ACK-185: Polish Dashboard Header & Summary Cards

## Summary

Improve the health dashboard with: an inline SVG favicon, header enhancements (last poll time, uptime), color-coded summary card borders, and a "Today" mini-stats row.

## Files to Modify

### 1. `src/health.ts` — Compute uptime locally before rendering

The `startHealthServer` function already captures `startTime = Date.now()` on line 37. Rather than adding `uptime` to the `HealthStatus` interface (which would require changes to `src/index.ts` and the `getStatus` callback), we compute uptime inside the dashboard route handler and pass it to `renderDashboard` as a second argument.

**Changes:**
- Update the `/dashboard` route handler (line 76-82) to compute `const uptime = Date.now() - startTime` and pass it to `renderDashboard`
- Update the `renderDashboard` function signature to accept a third parameter: `uptime: number`

This avoids duplicating start-time tracking and keeps the change minimal — no `HealthStatus` interface change, no `index.ts` change.

#### D. "Today" mini-stats row

Add a new section between the summary cards and the active critters section.

**Data computation** — reuse the existing `dailyStats` array (from `computeDailyStats`) rather than re-filtering all metrics. The last entry in `dailyStats` is always today (since `computeDailyStats` pre-fills the last N days ending at today):

```typescript
const todayStat = dailyStats[dailyStats.length - 1];
const todayCompleted = todayStat?.completed ?? 0;
const todayFailed = todayStat?.failed ?? 0;
const todayCost = todayStat?.cost ?? 0;
```

## Dependencies

- No new packages needed
- No external dependencies (inline SVG favicon)
- The `formatDate()` and `fmtDuration()` helper functions already exist and handle the formatting needs

## Edge Cases

- `status.lastPollAt` can be `null` (daemon just started, no poll yet) — display "never"
- `uptime` could be 0 on first render — `fmtDuration(0)` handles this gracefully (returns "0s" or similar)
- Today's stats will all be 0 if no tasks have run today — shows "0 completed | 0 failed | $0.00 spent"
- `dailyStats` always has at least one entry (today) since `computeDailyStats` pre-fills days, so `dailyStats[dailyStats.length - 1]` is safe. The `?.` guard is defensive.
