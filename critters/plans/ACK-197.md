# ACK-197: Add Client-Side Interactivity to Dashboard

## Summary

Add inline JavaScript to `src/dashboard.ts` for sorting, filtering, poll triggering, and smooth auto-refresh. The dashboard is currently entirely server-rendered with a `<meta http-equiv="refresh">` tag. This plan adds ~150-180 lines of vanilla JS as progressive enhancement.

## Files to Modify

### `src/dashboard.ts`

This is the only file that needs changes. All modifications are within the `renderDashboard()` function's template literal.

PR column is not sortable (it's just a link or dash). Each `data-sortable` value indicates the sort type.

#### Change 7: Add `data-sort-value` attributes to duration, cost, and date cells

To enable proper sorting of formatted values, add raw sortable values as data attributes on `<td>` elements:

- **Duration cells:** `<td data-sort-value="${m.duration ?? -1}">` — raw milliseconds
- **Cost cells:** `<td data-sort-value="${m.costUsd ?? -1}">` — raw number
- **When cells:** `<td data-sort-value="${m.timestamp}">` — ISO timestamp string

This avoids complex client-side parsing of formatted strings like "3m 45s" or "$12.50" or "2h ago".

##### Feature 1: Sortable activity table (~40 lines)

```javascript
(function() {
  const table = document.querySelector('.table-section table');
  if (!table) return;
  const thead = table.querySelector('thead');
  const tbody = table.querySelector('tbody');
  const headers = thead.querySelectorAll('th[data-sortable]');
  let currentSort = { col: -1, asc: true };

  headers.forEach(function(th, idx) {
    // Map th index to actual column index in the table
    const colIdx = Array.from(thead.querySelectorAll('th')).indexOf(th);
    th.addEventListener('click', function() {
      const asc = currentSort.col === colIdx ? !currentSort.asc : true;
      currentSort = { col: colIdx, asc: asc };

      // Clear existing arrows
      headers.forEach(function(h) {
        var arrow = h.querySelector('.sort-arrow');
        if (arrow) arrow.remove();
      });

      // Add arrow to active header
      var arrow = document.createElement('span');
      arrow.className = 'sort-arrow';
      arrow.textContent = asc ? '\u25B2' : '\u25BC';
      th.appendChild(arrow);

      // Sort rows
      var rows = Array.from(tbody.querySelectorAll('tr'));
      var sortType = th.getAttribute('data-sortable');

      rows.sort(function(a, b) {
        var cellA = a.cells[colIdx];
        var cellB = b.cells[colIdx];
        var valA, valB;

        if (sortType === 'duration' || sortType === 'cost' || sortType === 'date') {
          valA = cellA.getAttribute('data-sort-value') || '';
          valB = cellB.getAttribute('data-sort-value') || '';
          if (sortType === 'date') {
            valA = new Date(valA).getTime() || 0;
            valB = new Date(valB).getTime() || 0;
          } else {
            valA = parseFloat(valA) || -1;
            valB = parseFloat(valB) || -1;
          }
        } else {
          valA = (cellA.textContent || '').toLowerCase();
          valB = (cellB.textContent || '').toLowerCase();
        }

        if (valA < valB) return asc ? -1 : 1;
        if (valA > valB) return asc ? 1 : -1;
        return 0;
      });

      rows.forEach(function(row) { tbody.appendChild(row); });
    });
  });
})();
```

##### Feature 2: Activity table filter (~15 lines)

```javascript
(function() {
  var input = document.getElementById('activity-filter');
  var table = document.querySelector('.table-section table');
  if (!input || !table) return;
  var tbody = table.querySelector('tbody');

  input.addEventListener('input', function() {
    var query = input.value.toLowerCase();
    var rows = tbody.querySelectorAll('tr');
    rows.forEach(function(row) {
      var text = row.textContent.toLowerCase();
      row.style.display = text.includes(query) ? '' : 'none';
    });
  });
})();
```

##### Feature 3: Poll Now button (~20 lines)

```javascript
(function() {
  var btn = document.getElementById('poll-btn');
  if (!btn) return;

  btn.addEventListener('click', function() {
    btn.disabled = true;
    btn.textContent = 'Polling...';
    fetch('/poll', { method: 'POST' })
      .then(function(res) { return res.json(); })
      .then(function(data) {
        btn.textContent = 'Triggered!';
        setTimeout(function() {
          btn.textContent = 'Poll Now';
          btn.disabled = false;
        }, 2000);
      })
      .catch(function() {
        btn.textContent = 'Failed';
        setTimeout(function() {
          btn.textContent = 'Poll Now';
          btn.disabled = false;
        }, 2000);
      });
  });
})();
```

##### Feature 4: Auto-refresh with countdown (~40 lines)

```javascript
(function() {
  var INTERVAL = 30;
  var remaining = INTERVAL;
  var countdownEl = document.getElementById('refresh-countdown');
  var paused = false;

  // Pause refresh while user is interacting with filter
  var filterInput = document.getElementById('activity-filter');
  if (filterInput) {
    filterInput.addEventListener('focus', function() { paused = true; });
    filterInput.addEventListener('blur', function() { paused = false; });
  }

  function updateCountdown() {
    if (countdownEl) {
      countdownEl.textContent = 'Refreshing in ' + remaining + 's';
    }
  }

  function doRefresh() {
    var url = '/dashboard' + window.location.search;
    fetch(url)
      .then(function(res) { return res.text(); })
      .then(function(html) {
        var parser = new DOMParser();
        var doc = parser.parseFromString(html, 'text/html');
        var newBody = doc.querySelector('body');
        if (newBody) {
          document.body.innerHTML = newBody.innerHTML;
          // Re-run all our setup by re-executing the script
          var scripts = document.body.querySelectorAll('script');
          scripts.forEach(function(s) {
            var ns = document.createElement('script');
            ns.textContent = s.textContent;
            s.parentNode.replaceChild(ns, s);
          });
        }
      })
      .catch(function() {
        // On fetch failure, fall back to full reload
        window.location.reload();
      });
  }

  setInterval(function() {
    if (paused) return;
    remaining--;
    if (remaining <= 0) {
      remaining = INTERVAL;
      doRefresh();
    }
    updateCountdown();
  }, 1000);

  updateCountdown();
})();
```

## Key Design Decisions

1. **`data-sort-value` attributes** — Instead of parsing "Xm Ys" or "$X.XX" on the client, we embed raw values as data attributes during server rendering. This is more robust and avoids duplicating formatting logic in JS.

2. **Script re-execution after DOM swap** — After fetching fresh HTML and swapping `body.innerHTML`, we re-create `<script>` elements to re-initialize all event listeners. This is necessary because `innerHTML` doesn't execute scripts.

3. **Pause refresh during filter interaction** — When the search input is focused, the auto-refresh countdown pauses to avoid losing the user's filter text and focus state.

4. **Progressive enhancement** — The `<noscript>` meta refresh fallback ensures the page still auto-refreshes without JS. All other features (sorting, filtering, poll button) gracefully degrade — the page is still fully functional as a read-only server-rendered dashboard.

5. **No PR column sorting** — PR is either a link or a dash, not meaningful to sort by.

## Dependencies

None. All vanilla JS, no external files or build steps.

## Testing Approach

1. **Manual browser testing** — Start the daemon, visit `http://localhost:3847/dashboard`, verify:
   - Column headers show pointer cursor, clicking sorts rows with arrow indicator
   - Repeated clicks toggle ascending/descending
   - Filter input filters rows in real-time
   - "Poll Now" button sends POST, shows "Triggered!" feedback
   - Countdown timer counts down and refreshes without full page reload
   - Scroll position preserved after auto-refresh
   - Filter text and focus preserved (refresh pauses while focused)

2. **No-JS fallback** — Disable JavaScript in browser, verify `<noscript>` meta refresh still works, page renders correctly without interactive features.

3. **Type filter compatibility** — Test with `?type=create` URL parameter to ensure auto-refresh preserves the filter.

4. **Edge cases:**
   - Empty activity table (no rows to sort/filter)
   - Cells with em-dash values (duration/cost showing "—")
   - Network failure during auto-refresh (should fall back to full reload)
   - Rapid poll button clicks (button disabled during request)
