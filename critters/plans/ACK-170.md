# ACK-170: Add `--repo` flag to `gh` calls in `salvagePartialProgress`

## Summary

The `salvagePartialProgress` function in `src/unified-spawner.ts` calls `gh pr list` and `gh pr create` without a `--repo` flag, relying on `gh` to infer the repo from the git remote. This is fragile — shallow clones or unusual remote configurations can cause `gh` to fail to resolve the repo. Fix by extracting `owner/repo` from the task's `repoUrl` and passing `--repo owner/repo` to both `gh` commands.

## Files to modify

### 1. `src/utils.ts` — Add `extractOwnerRepo()` utility function

Add a new exported function that extracts `owner/repo` from a git URL. This is the natural home since `utils.ts` already contains small utility functions (`slugify`, `branchName`, `shellEscape`, etc.) and has no heavy dependencies.

```typescript
/**
 * Extract "owner/repo" from a git remote URL.
 * Supports:
 *   git@github.com:owner/repo.git
 *   https://github.com/owner/repo.git
 *   git@bitbucket.org:owner/repo.git
 * Returns null if the URL doesn't match.
 */
export function extractOwnerRepo(repoUrl: string): string | null {
  // SSH: git@host:owner/repo.git
  const sshMatch = repoUrl.match(/^git@[^:]+:(.+?)(?:\.git)?$/);
  if (sshMatch) return sshMatch[1];

  // HTTPS: https://host/owner/repo.git
  const httpsMatch = repoUrl.match(/^https?:\/\/[^/]+\/(.+?)(?:\.git)?$/);
  if (httpsMatch) return httpsMatch[1];

  return null;
}
```

### 5. `src/__tests__/utils.test.ts` — Add unit tests for `extractOwnerRepo`

Add a test block (or new file if `utils.test.ts` doesn't exist) covering:

- SSH URL: `git@github.com:org/repo.git` → `"org/repo"`
- HTTPS URL: `https://github.com/org/repo.git` → `"org/repo"`
- SSH without `.git` suffix: `git@github.com:org/repo` → `"org/repo"`
- HTTPS without `.git` suffix: `https://github.com/org/repo` → `"org/repo"`
- Bitbucket SSH: `git@bitbucket.org:team/project.git` → `"team/project"`
- Invalid URL: `"not-a-url"` → `null`
- Empty string: `""` → `null`
