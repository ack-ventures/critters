# ACK-252: Dashboard click-through from charts to filtered activity

## Summary

Make dashboard chart elements clickable so they filter the Recent Activity table. This builds on the ACK-246 filter infrastructure (filter buttons, `activeFilters` object, `applyFilters()` function, URL params) already present in the dashboard JavaScript.

## Changes

### 4. Add chart click handlers (inside the existing filter IIFE, after ~line 1241)

Integrate click handlers into the existing filter IIFE so they share `activeFilters` and `applyFilters()` references.

#### a) Daily bar chart / cost chart / duration chart click handler
```javascript
document.querySelectorAll('.charts .bar-group[data-date]').forEach(function(group) {
  group.addEventListener('click', function() {
    var date = group.getAttribute('data-date');
    activeFilters.date = (activeFilters.date === date) ? '' : date;
    updateDateDisplay();
    highlightChartElements();
    applyFilters();
    scrollToActivity();
  });
});
```

#### b) Stacked bar type segment click handler
```javascript
document.querySelectorAll('.charts .bar[data-chart-type]').forEach(function(bar) {
  bar.addEventListener('click', function(e) {
    e.stopPropagation(); // Prevent bar-group date click
    var typeName = bar.getAttribute('data-chart-type');
    activeFilters.type = (activeFilters.type === typeName) ? '' : typeName;
    filterBar.querySelectorAll('[data-filter-group="type"]').forEach(function(b) {
      b.classList.toggle('active', b.getAttribute('data-filter-value') === activeFilters.type);
    });
    highlightChartElements();
    applyFilters();
    scrollToActivity();
  });
});
```

#### c) Legend click handler

#### d) Donut chart click handler
```javascript
document.querySelectorAll('[data-chart-status]').forEach(function(el) {
  el.addEventListener('click', function() {
    var statusVal = el.getAttribute('data-chart-status');
    activeFilters.status = (activeFilters.status === statusVal) ? '' : statusVal;
    // Donut uses 'success'/'failure' which don't map to button values,
    // so deselect all and highlight the "All" button when a donut filter is active
    filterBar.querySelectorAll('[data-filter-group="status"]').forEach(function(b) {
      var bVal = b.getAttribute('data-filter-value');
      if (activeFilters.status === 'success' || activeFilters.status === 'failure') {
        b.classList.remove('active');
      } else {
        b.classList.toggle('active', bVal === activeFilters.status);
      }
    });
    highlightChartElements();
    applyFilters();
    scrollToActivity();
  });
});
```

#### e) Helper functions (inside the IIFE)

```javascript
function scrollToActivity() {
  var section = document.querySelector('.table-section');
  if (!section) return;
  var rect = section.getBoundingClientRect();
  // Only scroll if table is not already visible in viewport
  if (rect.top < 0 || rect.top > window.innerHeight) {
    section.scrollIntoView({ behavior: 'smooth', block: 'start' });
  }
}

function updateDateDisplay() {
  var container = document.getElementById('date-filter-display');
  if (!container) return;
  if (!activeFilters.date) {
    container.innerHTML = '';
    return;
  }
  var parts = activeFilters.date.split('-');
  var months = ['Jan','Feb','Mar','Apr','May','Jun','Jul','Aug','Sep','Oct','Nov','Dec'];
  var label = months[parseInt(parts[1],10)-1] + ' ' + parseInt(parts[2],10);
  container.innerHTML = '<span class="meta-sep">|</span> <span style="font-size:0.75rem;color:var(--text-dim);text-transform:uppercase;font-weight:600;">Date:</span> <button class="filter-btn active" id="date-filter-clear">' + label + ' &times;</button>';
  document.getElementById('date-filter-clear').addEventListener('click', function() {
    activeFilters.date = '';
    updateDateDisplay();
    highlightChartElements();
    applyFilters();
  });
}

function highlightChartElements() {
  // Highlight selected date bars
  document.querySelectorAll('.charts .bar-group[data-date]').forEach(function(g) {
    var isSelected = activeFilters.date && g.getAttribute('data-date') === activeFilters.date;
    var isDeselected = activeFilters.date && g.getAttribute('data-date') !== activeFilters.date;
    g.style.opacity = isDeselected ? '0.3' : '1';
    if (isSelected) {
      g.style.outline = '2px solid var(--text)';
      g.style.outlineOffset = '-1px';
      g.style.borderRadius = '3px';
    } else {
      g.style.outline = '';
      g.style.outlineOffset = '';
      g.style.borderRadius = '';
    }
  });

  // Highlight selected type segments / legend items
  document.querySelectorAll('[data-chart-type]').forEach(function(el) {
    var isSelected = activeFilters.type && el.getAttribute('data-chart-type') === activeFilters.type;
    var isDeselected = activeFilters.type && el.getAttribute('data-chart-type') !== activeFilters.type;
    el.style.opacity = isDeselected ? '0.3' : '1';
    if (isSelected && el.classList.contains('bar')) {
      el.style.outline = '2px solid var(--text)';
      el.style.outlineOffset = '-1px';
    } else {
      el.style.outline = '';
      el.style.outlineOffset = '';
    }
  });

  // Highlight donut segments
  document.querySelectorAll('[data-chart-status]').forEach(function(el) {
    var isDeselected = activeFilters.status && el.getAttribute('data-chart-status') !== activeFilters.status;
    el.style.opacity = isDeselected ? '0.3' : '1';
  });
}
```

### 6. Restore chart highlights after auto-refresh

The `doRefresh()` function (line 1292-1312) replaces body innerHTML and re-executes scripts. Since the filter IIFE reads URL params on init (`fdate`, `ftype`, `fstatus`) and calls `applyFilters()`, the table filter state is restored. To also restore chart highlights, add calls to `highlightChartElements()` and `updateDateDisplay()` at the end of the IIFE init block (after `applyFilters()` at ~line 1244):

```javascript
applyFilters();
highlightChartElements();
updateDateDisplay();
```

This ensures that after every auto-refresh (which re-executes the scripts), the chart visual state is restored from URL params.

### 7. Donut chart status mapping

The donut uses `data-chart-status="success"` and `data-chart-status="failure"`. The `applyFilters()` function handles these special values by matching against multiple activity statuses (see section 3). When the donut sets a status filter, no status filter button will be highlighted (since "success"/"failure" don't match button values) -- this is intentional. The clear button and clicking the same donut segment again both properly reset the state.

## Testing approach

1. **Manual testing via browser**:
   - Click a bar in the daily tasks chart -> verify activity table filters to that date, bar is highlighted, other bars dim, date pill appears in filter bar
   - Click same bar again -> verify filter clears, all bars restore opacity
   - Click a type segment in a stacked bar -> verify type filter activates, filter buttons sync
   - Click a legend item -> same type filter behavior
   - Click donut success segment -> verify shows only completed/review completed rows
   - Click donut failure segment -> verify shows only failed/review failed rows
   - Combine filters: click a date bar then a type segment -> both filters apply
   - Click "Clear filters" -> all chart highlights and filters reset, date display clears
   - Verify URL params update correctly (`fdate`, `ftype`, `fstatus`)
   - Refresh page with filter params in URL -> filters AND chart highlights restore correctly
   - Wait for auto-refresh (30s) -> verify filter state and chart highlights persist
   - Verify scroll behavior: clicking chart when table is off-screen scrolls to it; clicking chart when table is visible does not scroll

2. **Edge cases**:
   - Click a date with no activity rows -> shows 0 results with counter
   - Charts with no data -> no errors on click
   - Single type (no stacked bars) -> bar groups still clickable for date filter
   - Mobile layout -> click targets still work
   - Rapid clicking between different date bars -> no stale event listeners (innerHTML replacement cleans up)
