# ACK-215: Add critter type count to daemon startup log

## Summary

Add the number of configured critter types to the daemon startup log line so operators can quickly confirm how many types are active when the daemon starts.

## Files to Modify

### `src/index.ts` (line 261)

**Current code:**
```typescript
log(`Critters ${getDisplayVersion()} starting...`);
```

**New code:**
```typescript
log(`Critters ${getDisplayVersion()} starting (${config.critterTypes.length} type${config.critterTypes.length === 1 ? "" : "s"})...`);
```

This is a one-line change. `config.critterTypes` is a `CritterTypeConfig[]` (defined in `src/types.ts:80`), so `.length` is always available and accurate.

The pluralization handles both singular ("1 type") and plural ("3 types") cases correctly.

## Dependencies

None. No new imports or packages required.

## Testing Approach

1. **Type check**: Run `bun run typecheck` to verify no type errors.
2. **Manual verification**: Start the daemon and observe the startup log line includes the type count.
3. **Edge cases**: The default config synthesizes 2 types (`create` and `review`) via `synthesizeDefaultTypes()`, so the typical output will be `"starting (2 types)..."`. A config with a single custom type will show `"starting (1 type)..."`.
