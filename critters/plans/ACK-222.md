# ACK-222: Remove auto-restart from critters update command

## Summary

After `critters update` applies a new binary, it currently attempts to POST to `/restart` to restart the running daemon. This is unwanted because an update shouldn't restart a daemon that may have active critters. The auto-restart block should be removed, leaving only the success message that tells the user to restart manually.

## Files to modify

### `src/updater.ts`

1. **Remove the auto-restart block** (lines 295–334): Delete the entire `if (force)` block that:
   - Dynamically imports `node:fs`, `node:os`, and `yaml`
   - Reads config files to find `healthPort` and `dashboardToken`
   - POSTs to `http://localhost:<port>/restart`
   - Falls back to printing "Restart the daemon manually..."

2. **Update the success message** (line 293): Change `"Will take effect on next restart."` to include an explicit instruction to restart manually. New message:
   ```
   Update applied (v${currentVersion} → v${latestVersion}). Restart the daemon manually to use the new version.
   ```

3. **No import changes needed**: The `yaml` package is dynamically imported inside the removed block (`await import("yaml")`), not at the top of the file. The `node:fs` and `node:os` dynamic imports are also only in the removed block. The top-level `node:fs` imports (`existsSync`, `writeFileSync`, etc.) are still used elsewhere in the function. No import lines need to change.

## Files NOT modified

- No test changes needed — `src/__tests__/updater.test.ts` does not test the auto-restart behavior.
- No config changes needed.
- No other files reference this restart-after-update logic.

## Testing approach

- `bun run typecheck` — verify no type errors after removal
- `bun run lint` — verify no lint issues
- `bun test` — run existing test suite to confirm nothing breaks
- Manual verification: read the modified file to confirm the restart block is gone and the success message is correct

## Risk assessment

Low risk. This is a straightforward deletion of ~40 lines of self-contained code with no external dependencies or side effects on the rest of the function.
