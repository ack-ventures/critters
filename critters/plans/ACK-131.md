# ACK-131: Add age-based guard to work directory cleanup

## Summary

`cleanupStaleWorkDirs` in `src/git.ts:120` currently deletes any work directory not in the caller's `activeWorkDirs` set. This is dangerous because:

1. A critter accidentally running `bun run src/index.ts` starts a second daemon that calls `spawner.cleanupStale()` with an empty `activeWorkDirs` set, wiping all active work directories.
2. The `Spawner` periodic cleanup only knows about its own `activeWorkDirs`, not the `ReviewSpawner`'s, so it could delete review work directories (and vice versa).

The fix adds an age check: before deleting a directory, check its mtime and skip any directory modified within the last `maxAgeMinutes` (default 60). Since the default task timeout is 30 minutes and review timeout is 15 minutes, 60 minutes is a safe threshold.

## Files to modify

### 1. `src/git.ts` — Add age guard to `cleanupStaleWorkDirs`

**Current signature** (line 120):
```ts
export function cleanupStaleWorkDirs(baseDir: string, activeWorkDirs?: Set<string>): void
```

**New signature**:
```ts
export function cleanupStaleWorkDirs(baseDir: string, activeWorkDirs?: Set<string>, maxAgeMinutes?: number): void
```

**Changes**:
- Add `statSync` to the imports from `node:fs` (line 1)
- Add `maxAgeMinutes` parameter with default value of `60`
- Before calling `cleanupWorkDir(fullPath)`, stat the directory and check if `Date.now() - mtime.getTime() > maxAgeMinutes * 60_000`
- Only delete if the directory is older than `maxAgeMinutes`
- Wrap the `statSync` call in a try/catch — if the stat fails (e.g., directory was already deleted), skip it silently

**Updated function body**:
```ts
export function cleanupStaleWorkDirs(baseDir: string, activeWorkDirs?: Set<string>, maxAgeMinutes = 60): void {
  if (!existsSync(baseDir)) return;
  const entries = readdirSync(baseDir, { encoding: "utf-8" });
  const maxAgeMs = maxAgeMinutes * 60_000;
  for (const entry of entries) {
    const fullPath = `${baseDir}/${entry}`;
    if (activeWorkDirs?.has(fullPath)) continue;
    try {
      const stats = statSync(fullPath);
      if (Date.now() - stats.mtimeMs < maxAgeMs) continue;
    } catch {
      continue;
    }
    cleanupWorkDir(fullPath);
  }
}
```

### 2. `src/__tests__/git.test.ts` — Update tests for age-based guard

**Changes to existing tests**:

The existing `cleanupStaleWorkDirs` tests create directories and immediately try to delete them. Since the new default `maxAgeMinutes` is 60, these newly created directories will be skipped. The tests need to either:
- Pass `maxAgeMinutes: 0` to bypass the age check (for tests that are verifying the active-set logic), or
- Use `utimesSync` to set old mtimes on directories that should be deleted

**Updated existing tests**:

1. **"removes inactive dirs but keeps active ones"** — Use `utimesSync` to set old mtimes on dirs `a` and `c` (the ones expected to be deleted). Keep `b` recent. This tests both the active-set guard AND the age guard together.

2. **"cleans all dirs when no active set"** — Use `utimesSync` to set old mtimes on dirs `x` and `y`. This tests that old, non-active dirs are cleaned up.

**New tests to add**:

3. **"preserves recent directories even if not in active set"** — Create directories, do NOT set old mtimes, call `cleanupStaleWorkDirs(baseDir)` with no active set. Verify all directories are preserved because they're recent.

4. **"deletes old directories but preserves recent ones"** — Create two directories. Set one to an old mtime (2 hours ago), leave the other recent. Call `cleanupStaleWorkDirs(baseDir)`. Verify only the old one is deleted.

5. **"respects custom maxAgeMinutes"** — Create a directory with mtime 10 minutes ago. Call with `maxAgeMinutes=5` — should delete. Call with `maxAgeMinutes=15` — should preserve.

**Import changes**: Add `utimesSync` to the `node:fs` import.

**Helper**: Add a local helper function to set a directory's mtime to a specific age:
```ts
function setAge(dirPath: string, minutesAgo: number): void {
  const time = new Date(Date.now() - minutesAgo * 60_000);
  utimesSync(dirPath, time, time);
}
```
