# ACK-158: Handle corrupted JSONL lines in getRecentMetrics

## Summary

`getRecentMetrics()` in `src/metrics.ts` currently uses `.map()` with `JSON.parse()` on every line. If any single line is corrupted (truncated write, crash, etc.), the parse throws and the outer `try/catch` returns `[]`, losing all metrics. The fix wraps `JSON.parse` in a per-line try/catch using `.flatMap()` to skip corrupted lines while preserving valid ones, logging a warning for each skipped line.

## Files to modify

### 1. `src/metrics.ts` — line 56

**Change**: Replace `.map()` with `.flatMap()` that has per-line error handling.

**Current code** (line 56):
```typescript
return lines.slice(-n).map((line) => JSON.parse(line) as MetricEvent);
```

**New code**:
```typescript
return lines.slice(-n).flatMap((line) => {
  try {
    return [JSON.parse(line) as MetricEvent];
  } catch {
    logError(`Skipping corrupted metric line: ${line.slice(0, 100)}`);
    return [];
  }
});
```

This is a single-line change in the return statement. No other changes to the function or file are needed — `logError` is already imported at line 4.

### 2. `src/__tests__/metrics.test.ts` — add test case

**Change**: Add a new test inside the existing `describe("getRecentMetrics", ...)` block (after the "handles fewer entries than requested" test at line 121).

**New test**:
```typescript
test("skips corrupted lines and returns valid entries", () => {
  const file = join(tempDir, "metrics.jsonl");
  initMetrics(file);

  recordMetric({ timestamp: "", event: "task_started", issueId: "Z-1" });
  // Append a corrupted line directly to the file
  appendFileSync(file, "this is not valid json\n");
  recordMetric({ timestamp: "", event: "task_completed", issueId: "Z-2" });

  const recent = getRecentMetrics(10);
  expect(recent).toHaveLength(2);
  expect(recent[0].issueId).toBe("Z-1");
  expect(recent[1].issueId).toBe("Z-2");
});
```

This requires adding `appendFileSync` to the existing `node:fs` import at line 2 (which currently imports `existsSync` and `readFileSync`).
