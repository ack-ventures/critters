#### D. Elapsed time color coding in active critters detail table

Use the `timeoutMinutes` field (default 30 if not available) to determine elapsed time color:

```typescript
const elapsedMs = Date.now() - d.startedAt;
const elapsed = fmtDuration(elapsedMs);
const timeout = d.timeoutMinutes ?? 30;
const timeoutMs = timeout * 60 * 1000;
const elapsedPct = elapsedMs / timeoutMs;
const elapsedClass = elapsedPct > 0.8 ? "elapsed-danger"
  : elapsedPct > 0.5 ? "elapsed-warn"
  : "elapsed-ok";
// ...
<td class="${elapsedClass}">${elapsed}</td>
```

## Edge Cases

- **Custom phase names**: Phases that don't match `plan`/`exec`/`review` get a neutral badge style (no color background, just the pill shape)
- **Missing timeoutMinutes**: Falls back to 30 minutes for elapsed time color coding
- **Zero active critters with perType data**: Check all type counts, not just flat counts
- **No perType keys**: Falls back to checking flat `activeCritters`/`queuedCritters` counts (already handled in existing code path)
