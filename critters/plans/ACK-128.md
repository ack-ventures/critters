## Files to modify

### `src/claude.ts`

**Change**: Replace line 14 (the 6th entry in `PANE_COLORS`, index 5).

**Current value**:
```typescript
  { bg: "colour52",  fg: "colour196", label: "\x1b[1;31m", toolColor: "\x1b[31m"  },  // red
```


**Color rationale**:
- `bg: "colour58"` — dark olive/amber background (tmux 256-color), provides a warm dark base without alarm
- `fg: "colour220"` — gold/amber foreground (tmux 256-color), warm and readable against the dark background
- `label: "\x1b[38;5;220m"` — 256-color ANSI escape for gold/amber (matches fg)
- `toolColor: "\x1b[38;5;220m"` — same amber for tool output consistency

**Note on duplicate `bg`**: The existing `PANE_COLORS[9]` (orange, line 18) uses `bg: "colour58"`. However, this is fine — `bg` values are not required to be unique across entries (the orange entry at index 9 already shares `bg: "colour52"` with index 1 in the original array). The `fg` and label/toolColor values differ, so the two entries remain visually distinct: amber (colour220 fg) vs. orange (colour214 fg).

**Comment style**: Uses `// amber` to match the existing pattern of short color name comments (e.g., `// cyan`, `// green`, `// magenta`).
