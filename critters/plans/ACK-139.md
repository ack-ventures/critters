# ACK-139: Add `critters kickoff` to README and CLAUDE.md

## Summary

The `critters kickoff` command (added in ACK-135, implemented in `src/cli-kickoff.ts`) triggers an immediate poll of both the critter watcher and review watcher via the health HTTP endpoint, instead of waiting for the next poll interval. It's currently undocumented in both README.md and CLAUDE.md. This plan adds the missing documentation entries.

## Files to Modify

### 1. `README.md`

**Change:** Add `critters kickoff` to the Commands list at ~line 24 (after `critters logs`).

Insert this line between `critters logs <ID>` and `critters init-repo`:

```
- `critters kickoff` — trigger an immediate poll (instead of waiting for the next interval)
```

This placement keeps the commands in a logical order: daemon management commands first, then operational commands (`status`, `retry`, `logs`, `kickoff`), then setup commands (`init-repo`).

### 2. `CLAUDE.md`

**Change 1:** Add `src/cli-kickoff.ts` to the Key files table.

Insert this row after the `src/logs.ts` row (line 174) and before the `src/init-repo.ts` row (line 175), keeping CLI command files grouped together:

```
| `src/cli-kickoff.ts` | `critters kickoff` CLI command |
```

**Change 2:** The `healthPort` config entry is already present in CLAUDE.md at line 130. No change needed.

## Dependencies / Setup

None — these are documentation-only changes to two existing files.
