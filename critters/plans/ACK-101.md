### 2. `src/__tests__/helpers.ts` — Test helper utilities

Two helper functions for use by future test suites:

**`createTempDir()`** — Creates a temporary directory and returns its path plus a cleanup function.

```typescript
import { mkdtempSync, rmSync } from "node:fs";
import { join } from "node:path";
import { tmpdir } from "node:os";

export function createTempDir(): { path: string; cleanup: () => void } {
  const path = mkdtempSync(join(tmpdir(), "critters-test-"));
  return {
    path,
    cleanup: () => rmSync(path, { recursive: true, force: true }),
  };
}
```

- Uses `mkdtempSync` for unique temp directory names (avoids collisions in parallel test runs)
- Returns `{ path, cleanup }` — cleanup uses `rmSync` with `recursive: true, force: true`
- Prefix `critters-test-` makes it easy to identify test artifacts

**`createTestRepo()`** — Creates a bare git repo in a temp directory for testing git operations without network access.

```typescript
import { execSync } from "node:child_process";

export function createTestRepo(): { path: string; cleanup: () => void } {
  const { path, cleanup } = createTempDir();
  execSync("git init --bare", { cwd: path, stdio: "ignore" });
  return { path, cleanup };
}
```

- Reuses `createTempDir()` internally
- Runs `git init --bare` to create a bare repository
- Returns the same `{ path, cleanup }` interface for consistency

Both helpers use named exports (no default exports), matching the project convention.

## Testing Approach

- Run `bun test` to verify:
  - The smoke test in `src/__tests__/smoke.test.ts` passes
  - The existing `src/config.test.ts` continues to pass
  - Bun discovers tests in both `src/` and `src/__tests__/` automatically
- Run `bun run typecheck` to verify TypeScript compilation succeeds with the new files
- Run `bun run lint` to verify Biome linting passes (biome config targets `src/**/*.ts` which includes `src/__tests__/`)

## Design Decisions

1. **`__tests__/` directory vs co-located tests**: The task specifically requests `src/__tests__/` for the new files. This is complementary to the existing pattern of `src/config.test.ts` — both are valid and Bun discovers test files in subdirectories automatically.

2. **`mkdtempSync` for temp dirs**: Using `mkdtempSync` instead of a hardcoded path (like `src/config.test.ts` uses) ensures unique directory names and avoids collisions when tests run in parallel.

3. **`execSync` for git init**: Using `execSync` (synchronous) in the helper keeps the API simple — `createTestRepo()` returns synchronously, which is easier to use in `beforeEach`/`beforeAll` hooks. The `git init --bare` command is fast enough that async isn't needed.
