# ACK-141: Reduce pane title update interval to 10 seconds

## Summary

The periodic tmux pane title update in `src/index.ts` runs every 60 seconds, but the displayed uptime includes seconds (via `formatDuration`, e.g. "5m 2s"). This means the seconds component jumps by 60 on each update, making the display feel stale and jerky. Reducing the interval to 10 seconds will make the uptime counter feel responsive while remaining lightweight (`tmux select-pane -T` is a trivial command).

## Files to Modify

### `src/index.ts` (line 270)

Change the `setInterval` delay from `60_000` to `10_000`:

```diff
-    }, 60_000);
+    }, 10_000);
```

This is the only change needed. No other files are affected.

## Dependencies / Setup

None. No new dependencies, no config changes, no environment variable changes.

## Testing Approach

1. **Manual verification**: Run the daemon in a tmux session and observe that the main pane title updates every ~10 seconds with a smoothly incrementing uptime counter.
2. **Code review**: Confirm that only the interval constant changed — no behavioral or structural modifications.
3. **No automated tests needed**: This is a cosmetic UI timing change with no testable logic change.
