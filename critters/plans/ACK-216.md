# ACK-216: Add Docker build status to daemon startup log

## Summary

Add a log line during daemon startup that indicates whether the process is running inside a Docker container. This is useful for debugging and support. Detection uses the standard `/.dockerenv` file that Docker creates in every container.

## Files to modify

### `src/index.ts`

1. **Add import**: Add `existsSync` to the imports. It's from `node:fs` (used extensively across the codebase, e.g., `src/init.ts`, `src/config.ts`). Add a new import line:
   ```typescript
   import { existsSync } from "node:fs";
   ```
   This goes after the existing `import { spawnSync } from "node:child_process";` on line 3.

2. **Add Docker detection log**: After the main startup log line on line 261:
   ```typescript
   log(`Critters ${getDisplayVersion()} starting (${config.critterTypes.length} type${config.critterTypes.length === 1 ? "" : "s"})...`);
   ```
   Add the following:
   ```typescript
   if (existsSync("/.dockerenv")) {
     log("Running inside Docker container");
   }
   ```

   This placement is right after the "starting" log line and before `const startTime = Date.now();` on line 262. It's part of the initial startup log block, which is the natural place for environment info.

## No new files

No new files need to be created.

## Dependencies

None. `existsSync` from `node:fs` is a built-in Node/Bun API already used throughout the codebase.

## Testing approach

- **Manual verification**: Run the daemon outside Docker — no "Running inside Docker container" line should appear. Run inside Docker — the line should appear.
- **No unit test needed**: This is a single conditional log line with no branching logic, return values, or side effects beyond logging. The `existsSync` function is a well-tested standard library function. Adding a unit test would require mocking `existsSync` and `log`, which adds complexity without meaningful coverage.
- **CI**: Existing CI (`bun run lint`, `bun run typecheck`, `bun test`) will verify the import is valid and types are correct.
