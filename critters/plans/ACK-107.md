# ACK-107: Add unit tests for tailLines utility function

## Summary

Add a `describe("tailLines", ...)` block to the existing `src/__tests__/utils.test.ts` test file to cover the `tailLines()` function from `src/utils.ts`. The function takes a string and a number `n`, splits by newlines, and returns the last `n` lines joined back together.

1. **Add `tailLines` to the import** from `../utils.js` (line 10-16, add to the existing named import).

2. **Add a `describe("tailLines", ...)` block** inside the existing `describe("src/utils.ts", ...)` block, after the `formatPhaseStats` describe (before line 215's closing `});`). This follows the existing pattern of nesting per-function describes under the file-level describe.

### Test cases

| Test name | Input | Expected output | Rationale |
|---|---|---|---|
| `"more lines than N"` | `"a\nb\nc\nd\ne"`, `n=3` | `"c\nd\ne"` | Normal case — returns last 3 of 5 lines |
| `"fewer lines than N"` | `"a\nb"`, `n=5` | `"a\nb"` | When text has fewer lines than requested, returns all lines |
| `"empty string"` | `""`, `n=3` | `""` | Empty input returns empty string (split produces `[""]`, slice(-3) → `[""]`, join → `""`) |
| `"single line"` | `"hello"`, `n=3` | `"hello"` | Single line with no newlines returns that line |
| `"N = 0"` | `"a\nb\nc"`, `n=0` | `""` | Zero lines requested — `slice(-0)` returns the full array in JS, but `slice(0)` does too; however `"".split("\n").slice(-0)` returns `["a","b","c"]`. **Wait** — `slice(-0)` is `slice(0)` which returns the whole array. So `tailLines("a\nb\nc", 0)` actually returns `"a\nb\nc"`. The test should expect `"a\nb\nc"` to match the actual behavior. |
| `"exact match (N equals line count)"` | `"a\nb\nc"`, `n=3` | `"a\nb\nc"` | When N equals the number of lines, returns entire text |
| `"trailing newline"` | `"a\nb\n"`, `n=2` | `"b\n"` | Text ending with newline — split produces `["a","b",""]`, last 2 → `["b",""]`, joined → `"b\n"` |

### Corrected N=0 behavior

Looking at the implementation: `lines.slice(-0)` — in JavaScript, `-0` is treated as `0` by `Array.prototype.slice`, so `slice(-0)` returns a copy of the entire array. Therefore `tailLines("a\nb\nc", 0)` returns `"a\nb\nc"`. The test for N=0 must expect the full string, not an empty string.
