# ACK-188: Fix chart x-axis label overlap on smaller screens

## Summary

The dashboard's 14-day bar charts have overlapping x-axis labels on medium-width screens (~1200-1500px) because 4 charts fit in one row (via `auto-fit`) and the "Mon DD" date format is too wide. Two changes fix this: force a 2x2 grid layout so charts are wider, and use shorter date labels (day number only, with month shown only on month boundaries).

## File to modify

`src/dashboard.ts`

## Changes

### 1. Add `chartDateLabel` helper function

Add a new function after `formatShortDate` (after line 58):

```typescript
function chartDateLabel(dateStr: string, prevDateStr: string | null): string {
  const months = ["Jan","Feb","Mar","Apr","May","Jun","Jul","Aug","Sep","Oct","Nov","Dec"];
  const parts = dateStr.split("-");
  if (parts.length < 3) return dateStr;
  const day = parseInt(parts[2], 10);
  const month = parts[1];
  const monthIdx = parseInt(month, 10) - 1;

  // Show month name + day when month changes (or for the first label)
  if (prevDateStr == null) {
    return `${months[monthIdx] ?? month} ${day}`;
  }

  const prevParts = prevDateStr.split("-");
  if (prevParts.length >= 2 && prevParts[1] !== month) {
    return `${months[monthIdx] ?? month} ${day}`;
  }

  // Same month: just show the day number
  return `${day}`;
}
```

**Behavior**: For 14 days spanning Feb 21 - Mar 6:
- First label: "Feb 21"
- Same month: "22", "23", ..., "28"
- Month boundary: "Mar 1"
- After: "2", "3", "4", "5", "6"

### 2. Update `.charts` CSS grid (line 232)

**Before:**
```css
.charts { display: grid; grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); gap: 16px; margin-bottom: 24px; }
```

**After:**
```css
.charts { display: grid; grid-template-columns: repeat(2, 1fr); gap: 16px; margin-bottom: 24px; }
```

This forces a 2x2 grid on desktop, giving each chart roughly half the viewport width.

### 3. Add CSS overflow safety to `.bar-label`

**Update `.bar-label` (line 254)** — add `text-overflow: ellipsis` and `overflow: hidden`:
```css
.bar-label { font-size: 0.6rem; color: var(--text-dim); margin-top: 4px; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
```

Note: Do NOT add `overflow: hidden` to `.bar-group` — it has `position: relative` and serves as the containing block for tooltip pseudo-elements (`.bar-group[data-tooltip]:hover::after` and `.bar[data-tooltip]:hover::after`). Adding overflow hidden would clip these tooltips. The `text-overflow: ellipsis` on `.bar-label` alone is sufficient overflow protection.

### 4. Update mobile media query breakpoint (line 368)

**Before:**
```css
@media (max-width: 600px) {
```

**After:**
```css
@media (max-width: 768px) {
```

Also update the `.charts` rule inside the media query to remain `grid-template-columns: 1fr` (it already is, so no change needed there — charts stack to single column on mobile).

### 5. Update the 3 bar chart `.map()` calls to use `chartDateLabel`

All three bar charts (Tasks, Cost, Duration) currently use `formatShortDate(d.date)` for the bar label. Change each `.map()` to pass the previous date and use `chartDateLabel` for the label, while keeping `formatShortDate` for tooltips.

**Tasks chart (lines 533-546):**
```typescript
dailyStats
  .map((d, i) => {
    const successH = Math.round(((d.completed) / maxTasksPerDay) * 100);
    const failH = Math.round(((d.failed) / maxTasksPerDay) * 100);
    const shortDate = formatShortDate(d.date);
    const label = chartDateLabel(d.date, i > 0 ? dailyStats[i - 1].date : null);
    return `          <div class="bar-group" data-tooltip="${shortDate}: ${d.completed} completed, ${d.failed} failed">
            <div class="bar-stack">
              <div class="bar failure" style="height:${failH}%"${failH > 0 ? ` data-tooltip="${d.failed} failed"` : ""}></div>
              <div class="bar success" style="height:${successH}%"${successH > 0 ? ` data-tooltip="${d.completed} completed"` : ""}></div>
            </div>
            <div class="bar-label">${escapeHtml(label)}</div>
          </div>`;
  })
  .join("\n")
```

Key changes:
- Add `i` parameter to the `.map()` callback
- Add `label` variable using `chartDateLabel`
- Keep `shortDate` (from `formatShortDate`) for `data-tooltip`
- Use `label` for the `.bar-label` element

**Cost chart (lines 559-570):** Same pattern — add `i` param, compute `label`, use in `.bar-label`.

**Duration chart (lines 583-594):** Same pattern.

### 6. What NOT to change

- `formatShortDate` function — unchanged, still used in tooltips
- Donut chart (Success vs Failure) — no x-axis labels
- Y-axis labels — unaffected

## Testing approach

- **Month boundary**: With 14 days ending Mar 6, dates span Feb 21-Mar 6. The first label should be "Feb 21", then "22"-"28", then "Mar 1", then "2"-"6".
- **Same-month range**: If all 14 days are in the same month, only the first label shows the month name; rest are day numbers.
- **Grid layout**: At ~1200px width, 2 charts per row instead of 4. Each chart gets ~580px instead of ~290px.
- **Mobile (<=768px)**: Charts stack to 1 column, every-other label hidden, labels rotated.
- **Overflow**: Long labels on `.bar-label` get ellipsized; tooltips remain unclipped.
- **Tooltips**: Still show full "Mon DD" format from `formatShortDate`.
