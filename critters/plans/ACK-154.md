# ACK-154: Extract duplicate shellEscape into utils.ts

## Summary

`shellEscape` is duplicated in two files with identical logic — single-quote wrapping with escaped inner single quotes. This plan consolidates it into `src/utils.ts` and updates both consumers to import from there.

## Files to Modify

### 1. `src/utils.ts` — Add `shellEscape` export

Add the following named export at the end of the file (after `formatPhaseStats`):

```ts
export function shellEscape(s: string): string {
  return `'${s.replace(/'/g, "'\\''")}'`;
}
```

This matches the existing implementation from `src/claude.ts:308-310` exactly.
