# ACK-138: Tell planning critters to use Write instead of Edit for plan revisions

## Summary

Planning phase critters have `Write` but not `Edit` in their allowed tools (see `getPlanningAllowedTools()` at `src/prompt.ts:58-63`). When the reviewer requests revisions to the plan, the critter attempts to use `Edit` to update the plan file and gets blocked with permission errors. The fix is to update the instruction text in `buildPlanningPrompt()` to explicitly tell the critter to use `Write` instead of `Edit` when revising the plan.

## Files to Modify

### `src/prompt.ts`

**Change**: Update step 5 of the planning workflow instructions (line 121) to explicitly tell the critter to use `Write` (not `Edit`) when revising the plan file.

**Current text (line 121):**
```
5. If the reviewer output contains REVIEW_STATUS: NEEDS_REVISION, revise your plan:
```

**New text:**
```
5. If the reviewer output contains REVIEW_STATUS: NEEDS_REVISION, revise your plan (use the Write tool to rewrite the entire plan file — Edit is not available):
```

This is a single-line string change within the template literal in `buildPlanningPrompt()`. No other lines or functions are affected.

## What NOT to change

- Do **not** add `Edit` to `getPlanningAllowedTools()` — the planning phase should remain restricted to creating new files via `Write` only.
- No changes to `buildExecutionPrompt()`, `getExecutionAllowedTools()`, or any other function.

## Dependencies

None. This is a self-contained text change with no impact on types, imports, or other modules.
